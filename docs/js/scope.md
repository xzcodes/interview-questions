# 作用域与作用域链（Scope & Scope Chain）

## 1. 概念定义

- **作用域**：在 JavaScript 中，作用域指变量和函数的可访问范围。
- **作用域链**：作用域链是一系列作用域的顺序链接，内层作用域可以访问外层作用域的变量。

## 2. 产生原因 / 工作原理

- **产生原因**：作用域链确保函数内部可以正确访问外部变量，同时避免变量污染全局命名空间。
- **工作原理**：当函数执行时，会创建一个执行上下文（Execution Context）。每个上下文包含自己的变量对象（Variable Object）和指向外部环境的引用。查找变量时，会从当前作用域开始，沿着作用域链向外层查找，直到找到变量或者到达全局作用域。

## 3. 典型示例

```
function outer() {
  const outerVar = 'I am outer';
  function inner() {
    const innerVar = 'I am inner';
    console.log(outerVar);  // 可以访问外层作用域变量
  }
  inner();
}
outer();
```

- **解释**：在这个示例中，`inner` 函数可以访问 `outerVar`，因为它存在于外层函数的作用域中。查找顺序遵循作用域链，从内到外查找变量。

## 4. 应用场景

- **闭包实现**：作用域链是闭包形成的基础。
- **模块化代码**：通过函数作用域保护变量，避免全局污染。
- **变量访问控制**：管理变量的可访问性，确保内部状态安全。

## 5. 常见考点与陷阱

- **作用域链顺序**：变量查找从内到外，直到全局作用域。
- **闭包与作用域链**：闭包可以延长外部作用域变量的生命周期，容易造成内存泄漏。
- **变量遮蔽（Shadowing）**：内层变量与外层同名时，会遮蔽外层变量。

## 6. 优缺点总结

- **优点**：
    - 保证变量访问的可预测性；
    - 提供封装和数据保护机制；
    - 支持闭包和模块化编程。
- **缺点**：
    - 查找变量需要沿作用域链逐级查找，嵌套层数过多时性能下降；
    - 错误使用闭包容易造成内存泄漏。

## 7. 一句话总结

- 作用域链确保变量查找顺序和访问规则，使内层函数能够访问外层函数的变量，实现封装和闭包机制。

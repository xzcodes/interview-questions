# 原型与原型链（Prototype & Prototype Chain）

## 1.概念定义

- **原型**：每个 JavaScript 对象都有一个 `prototype` 属性，这个属性指向另一个对象，称为该对象的原型
- **原型链**：当访问对象的某个属性或方法时，如果该对象本身没有该属性/方法，JavaScript 会沿着原型链向上查找，直到找到该属性/方法或者到达链的顶端（即`null`）

## 2.产生原因/工作原理

- **工作原理**：JavaScript 使用原型链来实现继承和方法共享
- **原型链机制**：每个对象都有一个内部属性`[[Prototype]]`（可以通过`__proto__`或 `Object.getPrototypeof()` 获取），该属性指向它的原型对象。当访问一个属性时，JavaScript 会先在当前对象中查找该属性，如果没有，便会沿着原型链逐层查找，直到找到为止，或者达到链的末端。 

## 3.典型示例

```js
function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function() {
  console.log('Hello, ' + this.name);
};

const person1 = new Person('Alice');
person1.sayHello();  // Hello, Alice
```

- **解释**：在这个示例中，`person1` 是 `Person` 的实例，它通过原型链访问 `sayHello` 方法，这个方法并不在 `person1` 本身上，而是在 `Person.prototype` 上。

## 4. 应用场景

- **继承**：通过原型链实现对象的继承，允许一个对象继承另一个对象的方法和属性。
- **共享方法**：多个实例共享同一个方法，减少内存消耗。
- **动态修改原型**：在运行时修改对象的行为，扩展或修改原型链上的方法。

## 5. 常见考点与陷阱

- **`prototype` 和 `__proto__` 区别**：`prototype` 是函数的属性，而 `__proto__` 是对象的属性。`prototype` 用于构造函数和实例之间的继承关系，而 `__proto__` 用于访问对象的原型链。
- **`instanceof` 运算符**：判断一个对象是否在某个构造函数的原型链上。
- **原型链性能问题**：访问属性时，原型链的查找需要时间，过长的原型链可能影响性能，尤其在深层嵌套时。

## 6. 优缺点总结

- **优点**：
    - 实现继承关系，避免重复代码；
    - 方法共享，减少内存消耗；
    - 可以动态修改和扩展对象行为。
- **缺点**：
    - 无法直接访问原型链中的属性；
    - 查找性能会随着原型链的长度增加而降低。

## 7. 一句话总结

- 原型链实现了 JavaScript 对象的继承机制，允许对象通过查找原型链来访问共享的方法和属性。
